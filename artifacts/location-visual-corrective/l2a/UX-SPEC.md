# UX specification: L2A location visual corrective

Дата: 2026-08-13
Scope: Смолевичи, Дзержинск, Заславль, Логойск.

## Пользовательский путь

```text
H1 и короткое обещание → route-specific кухня → четыре кнопки-состояния
→ три заметных изменения currentSrc → короткое следствие выбора
→ два релевантных server link → существующие подробности и форма
```

## Контракт экрана

- `RegionalLocationPage` остаётся server shell и включает explorer только для активных route.
- Начальный кадр существует в server HTML, загружается eagerly и не зависит от hydration.
- `LocationVisualExplorer` остаётся единственным client island; controls недоступны только до hydration, без скачка layout.
- На 360–412 px изображение 3:2 предшествует controls; controls образуют сетку 2×2 и имеют touch target не меньше 44 px.
- На 768/1440 px сохраняется тот же порядок решения.
- Tabs поддерживают касание, мышь, Enter/Space, стрелки, Home/End; выбранное состояние имеет `aria-selected=true`.
- При выборе меняются `currentSrc`, заголовок и consequence; контейнер изображения сохраняет размер, scrollY не прыгает.
- ExploreContext сохраняет только город и выбранный сценарий без PII.
- Без JavaScript остаются вопрос, первый visual, disclosure и crawlable next links.

## Route-specific flows

| Route | Состояния | Результат |
| --- | --- | --- |
| `/locations/smolevichi` | квартира → дом → коммуникации → замер | Пользователь сравнивает тип объекта и видит, что проверить до чистовой отделки. |
| `/locations/dzerzhinsk` | квартира → семейная кухня → ящики → монтаж | Пользователь сравнивает масштаб кухни и подготовку к ежедневному использованию. |
| `/locations/zaslavl` | квартира → дом → техника → логистика | Пользователь сопоставляет городской и домашний сценарии до заноса и установки. |
| `/locations/logoisk` | дом → дача → инженерные зоны → монтаж | Пользователь сравнивает постоянный и сезонный режимы и видит инженерную подготовку. |

## SEO и provenance

- Metadata, canonical, H1, schema и sitemap не меняются.
- Все controls, последствия, alt и подписи — на русском языке.
- Изображения обозначаются как AI-концепции, а не выполненные проекты в городе.
- Длинный индексируемый контент остаётся после visual journey.
- Следующие маршруты существуют в canonical sitemap и остаются обычными server links.
