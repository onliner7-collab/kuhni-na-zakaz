# L0: аудит визуальных серий городов

Дата проверки: 2026-08-10
Источник: фактические `data/locations.ts`, `data/kitchen-ideas-3d.ts` и файлы `public/`.

## Итог

- В corrective scope: 28 generic-city маршрутов; Минск, Минская область и Борисов защищены.
- 11 маршрутов используют общий fallback из шести изображений: Жодино, Молодечно, Солигорск, Слуцк, Фаниполь, Смолевичи, Гомель, Гродно, Брест, Витебск, Могилёв.
- 17 маршрутов имеют route-specific набор только из трёх изображений: Дзержинск, Заславль, Логойск, Вилейка, Несвиж, Березино, Воложин, Столбцы, Узда, Червень, Марьина Горка, Клецк, Копыль, Крупки, Любань, Мядель, Старые Дороги.
- Ни один из 28 маршрутов до L0 не выполняет контракт из четырёх route-specific состояний с тремя изменениями `currentSrc`.
- Фактическое число трёхкадровых route-specific серий — 17, а не 11 из вводной части ТЗ. Для rollout используется проверенный код.

## Решение L0

- `REPLACE`: общий fallback для Солигорска, Фаниполя и Гомеля.
- `ADAPT`: generic branch `RegionalLocationPage` только для трёх пилотных route через отдельный registry gate.
- `KEEP`: Минск, Минская область и Борисов; текущие metadata/schema/lead contracts; длинный индексируемый контент после нового visual journey.
- `MOVE`: Related Exploration для пилотов после основного visual interaction.
- `REMOVE`: ничего; старые изображения остаются доступными для остальных волн до их приёмки.

## Статус

Пилотные серии принимаются только после визуального QA, WebP/AVIF parity, unit/e2e и production evidence. Остальные 25 маршрутов не получают фиктивный active-series status.
