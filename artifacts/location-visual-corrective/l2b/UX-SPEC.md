# UX specification: L2B location visual corrective

Дата: 2026-08-14
Scope: Вилейка, Несвиж, Воложин, Мядель.

## Пользовательский путь

```text
H1 и короткое обещание → route-specific кухня → четыре кнопки-состояния
→ три изменения currentSrc → короткое следствие выбора
→ два релевантных server link → существующие подробности и форма
```

## Контракт экрана

- `RegionalLocationPage` остаётся server shell и активирует существующий explorer только для четырёх L2B route.
- Начальный кадр присутствует в server HTML и загружается eagerly; остальные кадры — после намерения пользователя.
- На 360–412 px изображение 3:2 стоит до controls; кнопки образуют сетку 2×2 с touch target не меньше 44 px.
- Tabs поддерживают Tab, Enter/Space, стрелки, Home/End и видимый focus; выбранное состояние имеет `aria-selected=true`.
- При выборе синхронно меняются `currentSrc`, заголовок и consequence без скачка scroll и layout.
- ExploreContext хранит только город и выбранный сценарий без PII.
- Без JavaScript остаются вопрос, первый visual, disclosure и crawlable next links.

## Route-specific flows

| Route | Состояния | Результат |
| --- | --- | --- |
| `/locations/vileyka` | квартира → дом → дача → замер | Сравнить три масштаба помещения и подготовить доступ к геометрии. |
| `/locations/nesvizh` | светлая → древесная → хранение → проект | Сравнить выразительность отделки без потери практичного хранения. |
| `/locations/volozhin` | дом → дача → инженерная зона → монтаж | Проверить котёл, вентиляцию и маршрут установки до заказа. |
| `/locations/myadel` | дом → дача → рабочая зона → монтаж | Сопоставить постоянный и сезонный режим, материалы и подготовку установки. |

## SEO и provenance

- Metadata, canonical, H1, schema и sitemap не меняются.
- Все controls, последствия, alt и подписи — на русском языке.
- Изображения обозначаются как AI-концепции, а не выполненные проекты.
- Длинный индексируемый контент остаётся после visual journey.
- Next routes существуют в canonical registry; self-loop отсутствует.
- ТЗ называет `/scenarios/dlya-doma` приоритетным переходом для трёх route, но такого canonical URL нет; runtime использует существующий hub `/scenarios` и более узкие canonical страницы каталога.
