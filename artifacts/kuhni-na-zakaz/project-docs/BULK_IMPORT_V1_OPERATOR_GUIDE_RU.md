# Bulk Import v1: инструкция для оператора

Основной файл для работы:
- `project-docs/templates/bulk-import-v1-template.xlsx`

Технический источник истины:
- `project-docs/BULK_IMPORT_V1.md`

## Для кого этот пакет

Этот пакет нужен контентщику или менеджеру, который:
- заполняет Excel-файл
- загружает workbook в админку
- проверяет preview
- запускает `Confirm and apply`

Калькулятор и конфигуратор в `v1` не входят.

## Что входит в workbook

Поддерживаются только эти листы:
- `Kitchens`
- `Styles`
- `Materials`
- `Scenarios`
- `Portfolio`
- `Locations`

Что важно:
- используйте именно эти названия листов
- не добавляйте в workbook лишние листы
- строка `1` уже занята заголовками
- каждая следующая строка это одна запись

Если какой-то сущности в этом импорте нет, лист можно оставить пустым, но удалять его не обязательно.

## Как заполнять Excel

Общие правила:
- обязательно заполняйте `externalId` у каждой строки
- `externalId` должен быть уникальным внутри одного листа
- для уже существующей записи используйте тот же `externalId`, что и раньше
- `slug` для новой записи нужен; если оставить пустым, backend попробует сгенерировать его автоматически
- для уже существующей записи не пытайтесь менять `slug`: в `v1` он не обновляется
- числа пишите как числа без текста вокруг
- `published` заполняйте значением `published` или `draft`
- если в поле список строк, безопаснее разделять значения переносом строки

Форматы массивов:
- простые списки можно заполнять через перенос строки, запятую, `;` или `|`
- JSON-массивы нужны только там, где это прямо указано ниже

Поля, где нужен JSON-массив объектов:
- `Scenarios.features`
- `Locations.faq`
- `Locations.uniquePoints`
- `Locations.contentBlocks`

Примеры формата:

```json
[{"title":"Плюс","text":"Краткое описание"}]
```

```json
[{"q":"Вопрос","a":"Ответ"}]
```

```json
[{"emoji":"📍","title":"Локальный плюс","text":"Краткое описание"}]
```

```json
[{"type":"text","title":"Заголовок блока","text":"Текст блока"}]
```

## Как вставлять ссылки на фото

Разрешены только прямые ссылки на сам файл изображения:
- `http://...` или `https://...`
- ссылка должна открывать именно картинку, а не страницу просмотра
- для локального пути допустим только путь к файлу изображения с расширением

Что использовать:
- прямой URL файла изображения, который браузер открывает как картинку
- форматы вроде `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.svg`, `.avif`

Что не использовать:
- страницы просмотра, шаринга, галереи, альбомов
- ссылки, которые открывают HTML-страницу вместо файла
- ссылки на `postimg.cc` и `postimages.org`

Если сомневаетесь:
1. откройте ссылку в отдельной вкладке
2. если видите только картинку без страницы сервиса, ссылка подходит
3. если видите страницу сайта с кнопками, рекламой или рамкой просмотра, ссылка не подходит

## Как запускать импорт через админку

Путь в админке:
- `/admin/imports`

Порядок работы:
1. Откройте админку и перейдите в `Bulk import v1`
2. Выберите файл `bulk-import-v1-template.xlsx`, заполненный вашими данными
3. Нажмите загрузку файла и дождитесь `Preview`
4. Проверьте `summary`, список строк и блок `Errors и warnings`
5. Если есть `errors`, исправьте workbook и загрузите его заново
6. Если есть только `warnings`, осознанно проверьте их
7. Поставьте галочку подтверждения ограничений
8. Нажмите `Confirm and apply`

После apply:
- система покажет итог по `created`, `updated`, `unchanged`, `invalid`
- повторный apply для той же preview-сессии не нужен

## Чего нельзя делать

- не меняйте структуру workbook
- не переименовывайте поддерживаемые листы
- не добавляйте листы "для заметок" или "README" внутрь файла для импорта
- не оставляйте тестовые строки, черновики и примеры в тех же листах
- не дублируйте `externalId`
- не рассчитывайте, что `slug` обновится у уже существующей записи
- не вставляйте ссылки на страницы просмотра изображений
- не используйте старые колонки из других импортов без проверки в шаблоне
- не пытайтесь через `v1` импортировать калькулятор, homepage, blog, reviews или site settings

## Что оператору важно помнить

- `Preview` это обязательный шаг, не пропускайте его
- `Unchanged` это хороший результат для строк без реальных изменений
- `Warnings` не всегда критичны, но их нужно читать
- если preview истёк, workbook надо загрузить заново
- если импортировали реальные изменения, после apply обязательно пройдите post-import checklist
