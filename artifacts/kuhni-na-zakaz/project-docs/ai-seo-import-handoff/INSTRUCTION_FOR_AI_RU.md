# Инструкция для ИИ: заполнение Excel для SEO-импорта КухниBY

Тебе передают Excel-файл для массового импорта контента на сайт кухни на заказ. Нужно заполнить его так, чтобы данные можно было загрузить в админку сайта через `/admin/imports`, а созданные страницы помогали SEO в Google и Яндексе.

## Файлы

- `kuhniby-seo-import-template.xlsx` — основной пустой шаблон, заполняй его.
- `kuhniby-seo-import-example-filled.xlsx` — пример уже заполненного файла, используй как ориентир по стилю и формату.

## Важные ограничения

В файле должны быть только эти листы:

- `Kitchens`
- `Styles`
- `Materials`
- `Scenarios`
- `Portfolio`
- `Locations`

Не переименовывай листы. Не добавляй новые листы. Не меняй названия колонок в первой строке. Каждая строка после заголовков — одна запись.

В каждой заполненной строке обязательно нужен уникальный `externalId`. Это стабильный ID записи для повторных импортов. Если запись уже была импортирована раньше, используй тот же `externalId`.

Для новых записей заполняй `slug`. Пиши slug латиницей, маленькими буквами, через дефисы: `uglovaya-kuhnya-minsk`, `kuhni-modern`, `kuhnya-v-grodno`.

Поле `published` заполняй только значениями:

- `published`
- `draft`

Для SEO обычно ставь `published`, если строка готова к публикации.

## Главная SEO-задача

Не набивай текст ключевыми словами. Нужно создавать полезные, уникальные и естественные страницы. Каждая страница должна отвечать на реальный запрос пользователя: цена, сроки, материалы, планировка, город, примеры работ, особенности заказа.

Для каждой страницы заполняй:

- `seoTitle` — поисковый title, обычно 45-65 символов.
- `seoDescription` — описание для выдачи, обычно 120-160 символов.
- `seoKeywords` — если колонка есть, 3-8 фраз через запятую.
- `title`, `headline`, `h1` — человекочитаемые заголовки без переспама.
- `intro`, `description`, `content`, `localIntro` — нормальный полезный текст.

## Что заполнять по листам

### Kitchens

Карточки кухонь и типов кухонь.

Колонки:

`externalId`, `slug`, `title`, `description`, `category`, `style`, `material`, `priceFrom`, `priceTo`, `features`, `images`, `mainImage`, `seoTitle`, `seoDescription`, `published`

Рекомендации:

- `title`: коротко, например `Угловая кухня в современном стиле`.
- `description`: 2-4 предложения о кухне, планировке, материалах, преимуществах.
- `category`: тип кухни, например `Угловые кухни`, `Прямые кухни`, `Кухни с островом`.
- `features`: преимущества списком, можно через перенос строки.
- `priceFrom`, `priceTo`: только числа.
- `images`, `mainImage`: только прямые ссылки на изображения.

### Styles

SEO-страницы по стилям кухонь.

Колонки:

`externalId`, `slug`, `title`, `headline`, `description`, `intro`, `content`, `suitableFor`, `pros`, `cons`, `careGuide`, `pairsWith`, `budgetLevel`, `priceFrom`, `image`, `seoTitle`, `seoDescription`, `seoKeywords`, `order`, `published`

Рекомендации:

- Делай отдельные страницы под стили: современный, классика, минимализм, скандинавский, лофт.
- `content` должен объяснять, кому подходит стиль, какие фасады/цвета/столешницы выбрать, как стиль влияет на цену.
- `pros`, `cons`, `suitableFor`, `pairsWith` можно писать списком через перенос строки.

### Materials

SEO-страницы по материалам.

Колонки:

`externalId`, `slug`, `title`, `headline`, `description`, `intro`, `content`, `pros`, `cons`, `suitableFor`, `careGuide`, `budgetLevel`, `pricePer`, `priceFrom`, `image`, `seoTitle`, `seoDescription`, `seoKeywords`, `order`, `published`

Рекомендации:

- Пиши про ЛДСП, МДФ, пластик, эмаль, акрил, шпон, столешницы.
- Обязательно раскрывай плюсы, минусы, уход, кому подходит материал.
- Не обещай невозможное. Если точной цены нет, используй аккуратные формулировки.

### Scenarios

Страницы под сценарии и боли клиента.

Колонки:

`externalId`, `slug`, `icon`, `badge`, `title`, `headline`, `intro`, `seoTitle`, `seoDescription`, `seoKeywords`, `needs`, `solutions`, `features`, `tips`, `ctaText`, `ctaHref`, `order`, `published`

Рекомендации:

- Примеры сценариев: маленькая кухня, кухня до потолка, кухня без ручек, кухня для студии, бюджетная кухня, кухня для семьи.
- `needs`: потребности клиента списком.
- `solutions`: решения списком.
- `features`: JSON-массив объектов, если заполняешь структурно. Формат:

```json
[{"title":"Больше хранения","text":"Используем верхние шкафы до потолка и продуманную внутреннюю фурнитуру."}]
```

### Portfolio

Страницы выполненных проектов.

Колонки:

`externalId`, `slug`, `title`, `city`, `region`, `area`, `layout`, `style`, `material`, `priceFrom`, `priceTo`, `days`, `completedAt`, `description`, `task`, `constraints`, `solution`, `result`, `mainImage`, `images`, `photosBefore`, `photosAfter`, `featured`, `order`, `seoTitle`, `seoDescription`, `seoKeywords`, `published`

Рекомендации:

- Пиши как кейс: задача клиента, ограничения помещения, решение, результат.
- `city` и `region` помогают локальному SEO.
- `completedAt`: дата в понятном формате, например `2026-04-20`.
- `featured`: можно `true` или `false`.
- Фото — только прямые ссылки на изображения.

### Locations

Самый важный лист для локального SEO: страницы по городам.

Колонки:

`externalId`, `slug`, `city`, `region`, `title`, `h1`, `intro`, `description`, `priceFrom`, `deliveryCost`, `deliveryDays`, `measureCost`, `timelineText`, `visitDetails`, `installDetails`, `images`, `areas`, `workZone`, `mapEmbed`, `features`, `faq`, `localIntro`, `uniquePoints`, `contentBlocks`, `ctaHeadline`, `ctaSubtext`, `phone`, `address`, `seoTitle`, `seoDescription`, `published`

Рекомендации:

- Не делай одинаковые страницы с заменой города. Для каждого города нужен уникальный текст.
- Укажи особенности выезда, доставки, сроков, районов обслуживания.
- `areas`: районы/населенные пункты списком через перенос строки.
- `faq`: JSON-массив вопросов и ответов:

```json
[{"q":"Выезжаете ли на замер в Минске?","a":"Да, согласуем удобное время и подготовим проект кухни после замера."}]
```

- `uniquePoints`: JSON-массив локальных преимуществ:

```json
[{"emoji":"📍","title":"Выезд по городу","text":"Замерщик приезжает в удобное время и учитывает особенности помещения."}]
```

- `contentBlocks`: JSON-массив текстовых блоков:

```json
[{"type":"text","title":"Как заказать кухню в Минске","text":"Оставьте заявку, согласуйте замер, получите проект и расчет стоимости."}]
```

## Требования к текстам

Пиши на русском языке для рынка Беларуси. Не используй агрессивный переспам вроде “купить кухни купить кухни Минск дешево”. Лучше естественные формулировки:

- `кухни на заказ в Минске`
- `угловая кухня под размер`
- `кухня с замером и монтажом`
- `кухни из МДФ`
- `кухня для маленького помещения`

Каждый `seoTitle` должен быть уникальным. Каждый `seoDescription` должен быть уникальным. Не копируй один и тот же текст между городами, стилями или материалами.

## Форматы списков

Простые списки можно писать через перенос строки:

```text
Замер
Проект
Производство
Монтаж
```

JSON-поля заполняй только валидным JSON без лишних переносов внутри ключей. Кавычки должны быть двойными.

## Изображения

Используй только прямые URL к файлам изображений:

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.avif`

Не используй ссылки на страницы просмотра, альбомы, Google Drive preview, postimg.cc или postimages.org.

## Финальная проверка перед возвратом файла

Перед тем как вернуть заполненный Excel:

1. Проверь, что названия листов не изменены.
2. Проверь, что первая строка с колонками не изменена.
3. Проверь, что в каждой заполненной строке есть `externalId`.
4. Проверь, что нет дублей `externalId` внутри одного листа.
5. Проверь, что все `slug` латиницей и через дефисы.
6. Проверь, что `published` заполнен как `published` или `draft`.
7. Проверь, что `seoTitle` и `seoDescription` уникальны.
8. Проверь, что JSON в `features`, `faq`, `uniquePoints`, `contentBlocks` валидный.
9. Не оставляй тестовые строки, комментарии и черновики в файле для импорта.

## Что вернуть

Верни заполненный `.xlsx` файл в той же структуре. Не конвертируй его в CSV. Не добавляй новые листы с объяснениями внутрь Excel.
