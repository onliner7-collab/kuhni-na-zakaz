# Bulk Import v1: post-import checklist

Этот чеклист нужен сразу после `Confirm and apply`.

## Сначала проверьте результат в админке

- `Apply завершён`
- есть итог по `created`, `updated`, `unchanged`, `invalid`
- `invalid` после apply должен быть `0`
- если ожидались изменения, убедитесь что `created` и `updated` выглядят правдоподобно

## Обязательно откройте эти страницы

- `/`
- `/catalog`
- `/portfolio`
- `/materials`
- одну страницу кухни из импорта
- одну страницу локации из импорта

Если в pilot import использовались тестовые страницы проекта, дополнительно можно проверить:
- `/catalog/uglovye-kuhni`
- `/locations/brest`

## На что смотреть на страницах

- страница открывается без ошибки
- есть заголовок `h1`
- текст не пустой и не обрезан
- изображения отображаются
- нет очевидно битых картинок
- формы и CTA видны
- списки, FAQ и контент-блоки рендерятся

## Отдельно проверьте импортированные сущности

Для каждой реально изменённой записи:
- откройте страницу по `slug`
- проверьте заголовок
- проверьте ключевые тексты
- проверьте SEO-поля в админке или в исходных данных, если это критично для запуска
- проверьте, что картинки соответствуют этой записи

Для `Scenarios`:
- проверьте блок `features`

Для `Locations`:
- проверьте `faq`
- проверьте `uniquePoints`
- проверьте `contentBlocks`

## Если что-то пошло не так

- не запускайте повторный apply наугад
- вернитесь к workbook
- исправьте строку
- заново загрузите файл в `/admin/imports`
- заново проверьте preview
