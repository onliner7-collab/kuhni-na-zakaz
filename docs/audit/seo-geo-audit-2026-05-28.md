Самый большой кластер содержит 693 запроса. Внутри смешаны запросы разных намерений:

### 4. Минская область есть как хаб, но не как сеть страниц

`/locations/minskaya-oblast` полезна как хаб, но не заменяет страницы городов. По гео-запросам типа "кухни на заказ в Несвиже" или "купить кухню Березино" поисковик ожидает отдельный город, а не общий регион.

### 5. Нет достаточных локальных доказательств

Для топ-1 по городам нужны не только тексты. На каждой городской странице нужны:

- блок "как проходит замер в городе";

- ссылки на соседние города;
- CTA с cityKey;
- schema `Service`/`LocalBusiness`/`FAQPage`/`BreadcrumbList`.

Сейчас часть этого есть на крупных городах, но для 17 новых городов нужно подготовить контент и данные.

## Риски

- Если создать 17 городских страниц шаблонно, без различий и доказательств, они могут стать doorway-like страницами и не дадут роста.
- Если оставить пустые посадочные в Excel, импорт/контент-план будет продолжать распылять запросы.
- Если городские страницы не связать с хабом и соседними городами, часть новых URL останется слабо доступной.
- Если использовать неподтвержденные "реальные кейсы" для городов, это риск доверия. Лучше честно маркировать 3D/референс как пример и отдельно собирать реальные кейсы.
