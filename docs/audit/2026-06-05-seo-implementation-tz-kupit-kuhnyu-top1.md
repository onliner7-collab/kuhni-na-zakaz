## Главная цель

Подогнать сайт под коммерческие запросы:

- `кухни на заказ`
- `кухни на заказ минск`
- `купить кухню минск`
- `купить кухню в минске`
- `купить кухню на заказ`
- `купить кухню под заказ`
- `купить кухонный гарнитур минск`
- `купить кухню + город Минской области`
- `купить + тип кухни`
- `кухни на заказ + город Минской области`

Цель по бизнесу: усилить видимость и заявки в Google и Яндексе, особенно по Минску и Минской области.

Важное ограничение: топ-1 нельзя гарантировать техническим ТЗ. Это зависит от конкурентов, ссылок, поведения пользователей, отзывов, бренда, индексации, возраста страниц и алгоритмов Google/Яндекса. Формулировка цели для исполнителей: сделать сайт максимально релевантным и конкурентным для топ-1 по целевым кластерам.

## Общие правила для всех этапов

- Не создавать doorway-страницы вида `/kupit-kuhnyu-borisov`, `/kupit-kuhnyu-minsk`, `/kupit-uglovuyu-kuhnyu-minsk`.
- Не спамить точными фразами. Фразы `купить кухню`, `купить кухню в <городе>`, `кухня на заказ` использовать естественно.
- Все видимые тексты и alt-тексты на русском.
- Все файлы с кириллицей сохранять UTF-8 без BOM.
- После каждого этапа запускать минимум:
  - `pnpm --filter @workspace/kuhni-na-zakaz typecheck`
  - `pnpm --filter @workspace/kuhni-na-zakaz sitemap:check`
  - `pnpm --filter @workspace/kuhni-na-zakaz build`
- После production-деплоя проверять live URL через браузер и `curl/head`.
- После внедрения новых/измененных SEO-страниц отправлять приоритетные URL в Google Search Console и Яндекс Вебмастер через встроенный браузер Codex/Browser/Playwright. Не использовать логины/пароли в чате.

## Обязательные skills по этапам

Каждый новый чат должен открыть и использовать соответствующие `SKILL.md`:

- `technical-seo-developer` — кодовые SEO-изменения, metadata, canonical, sitemap, schema, деплой-проверки.
- `keyword-research` — проверка запросов, группировка, приоритеты.
- `on-page-seo-auditor` — аудит title, description, H1-H3, контента, изображений, внутренних ссылок.
- `meta-tags-optimizer` — title/description/OG для страниц.
- `schema-markup-generator` — JSON-LD: FAQPage, Service, Product/Offer, BreadcrumbList, LocalBusiness.
- `internal-linking-optimizer` — перелинковка между главной, каталогом, городами, блогом, ценами.
- `content-gap-analysis` — поиск недостающих блоков относительно конкурентов.
- `geo-content-optimizer` — Q&A, определения, таблицы и AI-citation-ready блоки.
- `accessibility-performance-qa` и `playwright`/`Browser` — финальная UI/SEO/адаптивная проверка.
