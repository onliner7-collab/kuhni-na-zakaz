## Что проверить после завершения позиции

Когда PixelPlus закончит обновление позиций, нужно выгрузить отчет по позициям и проверить:

1. Запрос.
2. Группу.
3. Поисковик.
4. Регион.
5. Позицию.
6. URL в выдаче.
7. Продвигаемый URL.
8. Дату проверки.

Главное для следующего SEO-анализа:

- где позиция уже в ТОП-10;
- где запросы находятся на позициях 11-30;
- где поисковик ранжирует не тот URL;
- где группа есть, но нет роста;
- какие страницы требуют усиления текстом, ссылками, фото, отзывами или правкой сниппета.
