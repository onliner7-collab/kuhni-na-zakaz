# Финальная карта запросов и приоритетов

Дата: 2026-06-06  
Основа: `docs/audit/2026-06-05-pixelplus-keyword-map.md`  
Сайт: `https://kuhni.minsk.by`

## Принципы

- Общие коммерческие запросы ведут на главную `/`.
- Транзакционные запросы `купить кухню Минск`, `купить кухню в Минске`, `кухню купить Минск`, `купить кухонный гарнитур Минск` ведут на `/catalog`.
- Локальные запросы по Минску про услугу ведут на `/locations/minsk`.
- Запросы `купить кухню + город` ведут на существующие `/locations/<city>`.
- Запросы по типу кухни ведут на категории каталога.
- Doorway-страницы вида `/kupit-kuhnyu-borisov` не создаются.

## Спорные решения

- `кухни без ручек на заказ`: сейчас ведет на `/styles` или существующую категорию `/catalog/kuhni-bez-ruchek`; для этапов 1-5 не делаем новой посадочной.
- `кухня для студии на заказ`: можно вести на `/scenarios/kuhnya-studiya` или `/catalog/malenkie-kuhni`; без doorway.
- `фасады для кухни Минск`, `кухни с фасадами эмаль`, `кухни со шпоном`, `столешницы для кухни на заказ`: пока поддерживать через `/materials`; отдельные страницы решать после анализа спроса и контента.
- `современные кухни`, `минимализм`, `неоклассика`, `лофт`, `белые кухни`, `серые кухни`: поддерживать через `/styles`, без смешивания с основными категориями каталога.

## Контроль этапа 1

- Все варианты `купить кухню + город` из PixelPlus и ТЗ имеют существующие `/locations/<city>`.
- Для P0 запросов нет посадочных без URL.
- Новые doorway-страницы не планируются.
