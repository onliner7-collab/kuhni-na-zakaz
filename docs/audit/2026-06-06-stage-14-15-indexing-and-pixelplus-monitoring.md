Мониторинг нужен не для разового отчета, а для еженедельного сравнения: позиции Google, позиции Яндекс, посадочная, изменение за неделю, что делать дальше.

### Правила реакции

| Ситуация | Действие |
|---|---|
| Запрос вырос на 1-3 позиции | Зафиксировать, не менять страницу 7 дней |
| Запрос рядом с топ-10: позиции 11-15 | Усилить сниппет, FAQ, внутренние ссылки и коммерческие доказательства |
| Запрос рядом с топ-3: позиции 4-6 | Проверить CTR, title/description, отзывы, фото, блоки доверия |
| Просадка на 3-5 позиций | Проверить индексацию, canonical, конкурентов в SERP, изменения title/H1 |
| Просадка больше 5 позиций | Запустить технический аудит, on-page аудит и проверку каннибализации |
| Ранжируется не целевая страница | Усилить целевую посадочную и добавить внутренние ссылки с естественными анкорами |
| Google растет, Яндекс нет | Проверить Яндекс Вебмастер: дубли title/description, переобход, региональность, текстовую релевантность |
| Яндекс растет, Google нет | Проверить GSC URL Inspection, schema, качество сниппета, Core Web Vitals и ссылочные сигналы |
