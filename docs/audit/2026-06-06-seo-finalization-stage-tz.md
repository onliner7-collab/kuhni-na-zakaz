## Этап 1. Актуализация карты запросов и приоритетов

Цель: зафиксировать финальную карту запросов после PixelPlus CSV и текущей структуры сайта.

Навыки:

- `keyword-research`
- `content-gap-analysis`
- `serp-analysis`

Задачи:

1. Открыть `docs/audit/2026-06-05-pixelplus-keyword-map.md`.
2. Проверить, что все варианты `купить кухню + город` есть в карте.
3. Разделить запросы на группы:
   - главная услуга;
   - купить кухню Минск;
   - купить кухню + город;
   - купить + тип кухни;
   - цены;
   - материалы;
   - портфолио/фото;
   - блог/информационные запросы.
4. Для каждой группы указать посадочную страницу.
5. Не создавать doorway-страницы вида `/kupit-kuhnyu-borisov`; использовать существующие `/locations/<city>`.

Критерий приемки:

- есть обновленная таблица `запрос -> кластер -> URL -> приоритет -> действие`;
- нет важных запросов без посадочной страницы;
- спорные запросы вынесены в список решений.
