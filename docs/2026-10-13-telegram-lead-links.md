# Ссылки Telegram на сохранённую заявку

Проблема: поле «Страница» вело на исходную публичную страницу и не показывало выбранные клиентом параметры. Пользователь расширил исправление на все уведомления со всех страниц сайта.

Решение: общий formatLeadCard добавляет ссылку /admin/leads/{publicNumber} с подписью «Открыть заявку и выбранные параметры». Исходная страница остаётся отдельной ссылкой. Детальная карточка читает сохранённую Lead, показывает контакты, фото, размеры, комментарий и вложенные answers; для калькулятора используется русская расшифровка selection и сохранённый результат, без нового расчёта по текущим тарифам. В списке заявок добавлена ссылка на детали.

Безопасность: существующая авторизация admin, проверка гостевого доступа к разделу leads, noindex, динамический серверный рендер. Без публичных токенов, контактов в URL и новых прав. Отсутствующая сессия перенаправляется на login с from=/admin/leads/{number}; после входа возвращает к заявке. Текст экранируется React; ссылки и картинки только с сайта. Исторические параметры, которые форма не сохранила, восстановить невозможно — в карточке это обозначено.

Проверки: unit 12/12 (формат Telegram, универсальные ответы, калькулятор, SSR вида, экранирование, URL), tsc passed. Production сборка и live проверка фиксируются в итоговом отчёте.

Старые сообщения: scripts/refresh-telegram-lead-links.ts, сначала preview, затем --apply. Редактирует только зарегистрированные сообщения; не создаёт замен удалённым. Переформатирует pending lead_card, чтобы отложенная доставка не вернула старые ссылки. Данные клиентов и chat ID в отчёт не выводятся.

База production: 7e538a1b1f32fbb198e2cee5472c6c670ff84fc0. Деплой с отдельной сборкой, сохранением старой .next и автоматическим откатом. Миграций и изменения публичных SEO-страниц нет.

## Итог

Production опубликован: 263bf0a6419f5f54067a95d8be930acfb449c422. Новая route присутствует в действующем .next/app-paths-manifest, service active, rollback build сохранён. /calculator отвечает 200. /admin/leads/1009 без сессии отвечает 307 на /admin/login?from=%2Fadmin%2Fleads%2F1009 с X-Robots-Tag noindex, nofollow, noarchive. Встроенный браузер не имел действующей административной сессии; проверка живой карточки после входа владельца не выполнялась. Серверный рендер карточки проверен unit и в браузере на синтетических данных: фото загружено, ширина 390 px, горизонтального переполнения нет.

Обновлены все 18 зарегистрированных Telegram-карточек для 9 заявок. Первая операция обновила 17; cardId=1 получил timeout. Целевая повторная операция успешно отредактировала cardId=1 без новых сообщений. Формат основной карточки сохранён, добавлена ссылка на заявку; прежняя ссылка явно подписана как исходная страница сайта. Новые уведомления любых активных форм используют общий formatLeadCard.
