# Этап 3 — карта содержания и diff-аудит

17.10.2026. Реализация и деплой явно разрешены пользователем.

| Старый блок | Решение | Результат |
|---|---|---|
| Визуальная проверка / MaterialDecisionExplorer | KEEP | Тот же компонент, конфигурация, ID и четыре ракурса, в основном потоке |
| Фото материала и кухонь / MaterialDetailGallery | KEEP | Тот же компонент, восемь фото и увеличение, в основном потоке |
| Первый экран и боковая колонка | REPLACE | Фото кухни, короткий H1, явные действия сравнения и расчёта |
| Старое DB/fallback содержание, плюсы/минусы, советы, стили, кейсы | REPLACE | Фасад/корпус/кромка, декоры, зоны эксплуатации, иллюстрированные альтернативы |
| Ценовые заметки | REPLACE | Два общих состава из MATERIAL_PRICE_SCENARIOS, исследование с оговорками |
| FAQ, форма, ссылки | ADAPT | 9 вопросов, прежняя система лидов, общий выбор, контекстные переходы |

Специализированный маршрут app/materials/ldsp/page.tsx переработан; остальные детальные маршруты не переписываются. МДФ и Борисов page-specific не изменяются. В релизе исходники двух сохранённых фотоблоков совпадают с production baseline; прежние локальные правки других задач в них не включаются.

Blum, Hettich, Gola, ПУР — кандидаты к подтверждению, не обещание доступности. Вопросы воды/пара/дачи рассматриваются как проверка условий. Ключи не вставляются списком в видимый контент.

Состояние ldspView в едином store: construction, decor, room, alternative. Не меняет comparisonIds, preferredId, updatedAt выбора; без контактов. Старые сохранения мигрируют к значениям по умолчанию. Два прежних фотоблока сохраняют существующее локальное состояние как до этого этапа; их ракурс/увеличение не превращается в явный выбор.
