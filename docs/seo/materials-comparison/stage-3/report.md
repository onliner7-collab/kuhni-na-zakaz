Подготовлен узкий релиз от фактического production baseline 59536c77445690f3f4405eb53f2c21134f06ed9e. Посторонние dirty-изменения рабочей папки не включаются. ## Открытые данные и пределы

Нужны действующие серии/декоры/толщины/кромки и собственные сметы бизнеса, допуски условий дачи, подтверждённые сопоставимые предложения для числовой вилки. Существующие два фотоблока сохраняют свой прежний локальный ракурс/lightbox; новый ldspView и явный выбор восстанавливаются общим store. Изображения — иллюстрации, не доказательство выполненных объектов. Search Console и Яндекс Вебмастер не входят в текущий объём. Следующий этап — эмаль по исходному мастер-ТЗ.
