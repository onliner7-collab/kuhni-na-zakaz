# Семантика /materials — 14 октября 2026

Готово исследование кандидатов и карта содержания. Пользователь дополнительно задал много фотографий и приоритет мобильной версии. Эти требования внесены в content-map.md.

## Результат

- 262 уникальных кандидата для `/materials`, 17 тематических кластеров.
- 77 дополнительных кандидатов распределены по другим существующим адресам; это начальные границы для следующих этапов, не отдельные ядра по 150 запросов.
- 18 исключенных или отложенных формулировок с причинами.
- 365 строк в сыром наборе: 339 принятых гипотез, 8 заголовков источников, 18 отложенных/отклоненных.
- По дополнительному запросу пользователя добавлены 36 формулировок со словом «купить». Всего в принятом ядре 45 таких кандидатов. Это ручное расширение по ранее исследованным темам, без нового измерения спроса.
- Изучены 5 московских и 3 белорусских источника. Белорусский AVVA — источник терминологии отдельных фасадов, не цен полной кухни.
- Частотность, сложность, реальные позиции и трафик не измерялись. Все 339 принятых строк помечены hypothesis. Список не является подтвержденным спросом.
