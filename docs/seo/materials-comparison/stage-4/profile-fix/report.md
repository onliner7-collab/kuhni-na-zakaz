# Исправление переключения фрезеровок — 17 октября 2026

Пользователь сообщил, что блок «Фрезеровка: от плоскости к рамке» не меняет фото. Прежняя реализация сдвигала один и тот же общий снимок через transform; src оставался прежним, и кадрирование делало различие профилей недостаточно понятным. Прежний тест проверял значение transform, а не реальную смену фото.

Заменено на три отдельных файла: profile-smooth.webp, profile-thin-frame.webp, profile-deep-frame.webp. Каждое нажатие меняет src, alt и изображение целиком; манипуляции увеличенным общим снимком удалены. Образцы одного цветового направления позволяют видеть разницу геометрии. Новые фотографии сгенерированы встроенным image_gen, проверены визуально. PNG сохранены в public/images/mdf-enamel-20261017/, рядом WebP 1200×800 весом 7 728 / 11 186 / 14 992 байта. Промпты: image-prompts.json.

Другие блоки, сравнение и общий store не переписаны. Сохраняется прежнее enamelView.profile, состояние Back/Forward/refresh, выбор и срок предпочтения.

Локально: production build Next 15.3.9 и типизация PASS. check-enamel-profiles.ts — PASS: 360/390/412/768/1440 px × reduce/no-preference × 3 состояния; три разных src и три разных хеша отрисованных изображений в каждом случае, без переполнения, сохранение после refresh/Back/Forward, отсутствие изменения сравнения/предпочтения/updatedAt, 3 WebP + 3 watermarked-image HTTP 200. Скриншоты и отчёт: local/.

Статус публикации и production-проверки будет зафиксирован после активации исправления.
