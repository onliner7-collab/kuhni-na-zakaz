## KEEP / ADAPT / REPLACE / MOVE / REMOVE

- `KEEP`: URL, canonical/metadata/schema, Server Component shell, ExploreContext, Lead pipeline, transition links и подробный server-rendered контент.
- `ADAPT`: `StyleVisualExplorer` — tab semantics, Arrow/Home/End, active-only panel, стабильный visual frame; shared Dock — scroll direction и interaction suppression.
- `REPLACE`: по одной generic/reused картинке заменены 18 route-specific continuity masters.
- `MOVE`: не требуется; visual, controls и active explanation уже собраны в одном смысловом mobile-блоке.
- `REMOVE`: generic config images больше не используются как основная series этих routes.
