## Boundary budget

- Page/layout остаются Server Components.
- На каждый пилот — один главный interactive island; небольшие picker/form wrappers допускаются отдельно.
- Никакого shared client state между пилотами. Context передаётся в форму сериализуемым summary.
- Dynamic import применяется только к below-fold interaction с заметным JS/media payload и обязательным server fallback.
