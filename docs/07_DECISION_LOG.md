## 2026-07-13 — документационный baseline и медиакарты пилотов

**Решение:** создать корневой `AGENT.md`, документацию 00–07 и manifest-first медиасистему для `/catalog/uglovye-kuhni`, `/locations/borisov`, `/materials/furnitura`, не меняя production-код.

**Причина:** следующие этапы должны расширять существующее приложение без потери URL/SEO и без слепой генерации несогласованных кадров.

**Какие файлы затронуты:** `AGENT.md`, `docs/00_PROJECT_VISION.md` — `docs/07_DECISION_LOG.md`, `content/media/pilots/*.json`, `public/media/pilots/*/.gitkeep`.

**Риски:** singular `AGENT.md` не является стандартным автоподхватываемым именем для всех агентов; поэтому обязательные действующие правила также остаются в существующем `AGENTS.md`. Manifest использует наследование defaults, которое будущий loader должен разрешать явно.

**Как откатить:** удалить только перечисленные новые документы, manifests и пустые pilot-каталоги; production-код и текущие страницы не затрагиваются.

## 2026-07-13 — этап 3: интерактивная страница угловых кухонь

**Решение:** сохранить URL `/catalog/uglovye-kuhni`, но отдать для него отдельную серверную оболочку с изолированным клиентским шоурумом, новыми сгенерированными изображениями и контекстным мобильным Dock.

**Причина:** посетителю нужно понять планировку, доступ к углу, различия механизмов и факторы цены до отправки заявки. Полноценный 3D для этого избыточен.

**Какие файлы затронуты:** маршрут категории, `components/catalog/angular-kitchens/*`, `lib/mobile-dock.config.js`, тест этапа и `artifacts/kuhni-na-zakaz/public/media/pilots/angular-kitchens/*`.

**Риски:** 12 последовательных кадров визуально близки, потому что показывают одно непрерывное открытие. Они не выводятся отдельной галереей: интерфейс держит в DOM только выбранный кадр.

**Как откатить:** удалить специальную ветку для slug `uglovye-kuhni`, конфигурацию `angularKitchen`, новый компонент, тест и каталог новых изображений; общий шаблон категории останется доступен.
