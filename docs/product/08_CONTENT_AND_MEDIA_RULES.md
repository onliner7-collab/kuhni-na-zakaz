# Правила контента и медиа

## Функция изображения

Каждое изображение отвечает на конкретный вопрос:

- как выглядит угловая кухня с открытой системой хранения;
- как направляющая обеспечивает доступ к ящику;
- как выглядит акриловый фасад при боковом свете;
- чем идея отличается от выполненного объекта;
- какой этап заказа объясняет иллюстрация.

Формулировка «красивая кухня» не является достаточной задачей медиа.

## Provenance gate

| Статус | Пользовательская группа | Можно в «Наши работы» |
| --- | --- | --- |
| Подтверждённый реальный объект | Наша работа | Да |
| AI/3D | Идея кухни / визуализация | Нет |
| Technical render | Техническая иллюстрация | Нет |
| Process illustration | Иллюстрация процесса | Нет |
| Unknown/source unknown | Идея/пример с нейтральной подписью | Нет |

Минимальное подтверждение реального проекта должно связывать запись с источником и правом публикации. Папка `/uploads/portfolio`, DB type, город или человекоподобное изображение не заменяют подтверждение.

## Текущие риски

- `/portfolio` импортирует `GENERATED_MINSK_PORTFOLIO_CASES`; generated cases не могут оставаться в целевой группе «Наши работы».
- `getImageDisclosure` классифицирует часть путей `/uploads/portfolio/` как portfolio по пути, а не по доказательству происхождения.
- Главная показывает generated и другие записи под заголовком «Реальные кухни, которые уже установлены».
- 203 изображения фурнитуры имеют `SOURCE_UNKNOWN` и не становятся реальными/лицензированными автоматически.

Этап 4.5 фиксирует проблему, но не меняет данные и UI.

## Контентные семейства

- Каталог/идеи: концепты, формы, стили, материалы, варианты комплектации.
- Наши работы: подтверждённые кейсы, задача, решение, материалы, город только при доказательстве.
- Материалы: фактура, уход, плюсы и ограничения без неподтверждённых характеристик.
- Механизмы: движение и назначение без выдуманных нагрузок, циклов и гарантии.
- Локации: реальные условия работы; иллюстрации отдельно от локальных доказательств.
- Блог: ответ, сравнение, чек-лист или объяснение; затем естественный переход.

## Loading

- Один true LCP hero может быть priority.
- Ниже fold — lazy с width/height или aspect ratio.
- Скрытые galleries, sequences и menu media не загружаются полным набором до intent.
- WebP/AVIF являются visible src; PNG/JPEG master хранится в проекте, но не подключается как основной тяжёлый файл.
- На mobile не раздаётся desktop master без необходимости.
- Missing media имеет текстовый fallback и не блокирует CTA.

## Интерактивные серии

- одна камера, геометрия, свет и материалы;
- меняется только заявленное состояние;
- poster first;
- соседний кадр после intent;
- reduced motion использует дискретные состояния;
- изображение не является единственным носителем ответа.

## Контентный acceptance

- один основной пользовательский и поисковый intent на URL;
- текст не раскрывает внутреннюю SEO-задачу;
- факты проверены;
- профессиональные термины объяснены;
- идея/работа разделены;
- русские alt/caption;
- обычные ссылки ведут к следующему шагу;
- важный смысл доступен в server HTML;
- медиа не создаёт лишний initial payload.
