# Карта переходов

Все переходы ниже — обычные полезные ссылки. Их внедрение выполняется адресно после diff-аудита; stage 4.5 не меняет страницы.

## Обязательные выходы по группе

| Группа | Обязательные переходы |
| --- | --- |
| Главная | выбор формы, стили, сценарии, материалы, идеи, наши работы, цены, заявка |
| Категория кухни | стили, материалы, механизмы, подтверждённые проекты, цены, расчёт, локации |
| Стиль | формы, материалы, подтверждённые проекты, цены/расчёт |
| Сценарий | подходящие категории, стили, материалы, проект/идея, цены, расчёт |
| Материал | сравнение, подходящие кухни, механизмы, подтверждённые проекты, расчёт |
| Фурнитура | категории кухни, материалы, цена, подбор, статья со sourced comparison |
| Наши работы | форма, стиль, материалы, локация, похожий подтверждённый проект, расчёт |
| Идея кухни | форма, стиль, материал, похожая реальная работа при наличии, расчёт |
| Локация | типы кухонь, замер, доставка, подтверждённые проекты/empty state, идеи, расчёт |
| Цены | категории, материалы, проектирование, калькулятор, заявка |
| Калькулятор | объяснение результата, цены, подходящая категория, проект/работа, заявка |
| Статья | категория, материал, подтверждённый проект или идея, расчёт |
| Доверие/сервис | наши работы, процесс, цены, контакты/заявка |
| Юридическая | возврат к выбору, цены, наши работы, заявка через глобальный Dock |

## Граф основных переходов

```text
Главная
├── Выбрать кухню
│   ├── Форма ──→ Стиль ──→ Материалы ──→ Механизмы
│   └── Сценарий ──→ Подходящая форма
├── Идеи кухонь ──→ Категория/стиль/материал
├── Наши работы ──→ Реальный проект
└── Цены ──→ Калькулятор

Любая ветка ──→ Оставить заявку
```

## Текущие смысловые тупики и слабые места

Фактический code/live baseline не показал ключевых страниц без единой ссылки: global chrome и текущий Dock обычно дают выход. Но следующие поверхности являются смысловыми тупиками или зависят от client-only/global навигации сильнее, чем от контекста страницы:

1. `/styles` — ведёт в стили и длинную форму, но в теле страницы нет полноценного следующего шага к форме кухни, материалам, подтверждённым работам и цене.
2. `/scenarios` — ведёт в сценарии и контакты, но hub не показывает явный мост к подходящим категориям, материалам, работам и цене.
3. Главная — подпись «SEO-страница категории» объясняет внутреннюю задачу вместо пользовательского перехода.
4. Главная — блок «Реальные кухни» смешивает визуализации и возможные portfolio-фото, поэтому переход не даёт достоверного ответа «что реально сделано».
5. `/portfolio` — generated cases фактически попадают в коллекцию; до provenance gate переход в «Наши работы» вводит в заблуждение.
6. `/catalog` и `/styles` при недоступной БД могут показывать empty state, который сообщает о хранилище/импорте вместо полезных ссылок на устойчивые fallback-направления.
7. Юридические страницы имеют выход через chrome, но не проектировались как часть постоянного конверсионного пути; новый Dock закрывает этот разрыв.

## Приоритет исправления переходов

- P0: provenance split «Идеи кухонь» / «Наши работы»; запрет технического языка; постоянная заявка.
- P1: `/styles`, `/scenarios`, `/catalog`, `/portfolio` как hubs без тупиков.
- P1: category/style/material/location/article transition blocks.
- P2: доверие, сервис и юридические страницы.

## Acceptance перехода

- ссылка существует и ведёт на реальный URL;
- anchor объясняет пользу;
- destination соответствует поисковой роли;
- ссылка доступна без JS;
- нет массового exact-match повторения;
- на mobile target минимум 44 px;
- переход не выдаёт визуализацию за выполненную работу.
