# SEO Strategy

- Главная: основной коммерческий кластер «купить кухню» и близкие вариации; не дублировать его на /catalog или /locations/minsk.
- Один URL — одна основная поисковая задача. Категории отвечают за тип кухни, locations — за город, materials — за материал/фурнитуру, статьи — за информационный вопрос, portfolio — за доказательство и long tail.
- Не создавать массовые «город × тип кухни × стиль» и фиктивные филиалы.
- Существующие URL, redirects, canonical, robots и sitemap сохраняются до отдельного решения и карты миграции.
- Важный текст, H1, FAQ по видимому содержанию и внутренние ссылки доступны в server-rendered HTML; интерактив не является единственным носителем смысла.
- Metadata: уникальные title/description, один абсолютный canonical, согласованные Open Graph/Twitter; не менять массово без query map и regression audit.
- Schema: только подтверждённые видимым контентом Organization/LocalBusiness, Service, Product, Article, FAQ и BreadcrumbList. Не размечать выдуманные reviews, prices или locations.
- Breadcrumbs и обычные HTML-ссылки связывают hubs с дочерними страницами. Анкоры описательны, без механического exact-match повторения.
- Alt описывает функцию/содержание изображения по-русски; decorative images получают пустой alt. AI-status указывается в caption/контексте, когда изображение можно принять за реальную работу.

## Зоны каннибализации

| Зона                                   | Роли                                                               |
| -------------------------------------- | ------------------------------------------------------------------ |
| /, /catalog, /prices, /locations/minsk | купить / выбрать тип / понять цену / заказать в городе             |
| category vs scenario vs blog           | коммерческий тип / бытовая задача / информационное объяснение      |
| materials hub vs detail vs article     | навигация / выбор материала / образовательное сравнение            |
| locations                              | уникальный городской сервисный вопрос, не копия с заменой названия |

Источники этапа: фактические Next.js metadata/sitemap/robots/schema helpers и production sitemap. Внешние Google/Yandex панели в данном этапе не изменялись и не использовались для заявлений об индексации.
