## Логика индексируемых страниц

Каждая SEO-страница должна:
1. Иметь уникальный H1 с ключевым запросом
2. Иметь уникальный title (до 60 символов)
3. Иметь уникальное meta description (155-160 символов)
4. Содержать минимум 500 слов текста
5. Иметь хотя бы 3 внутренние ссылки
6. Иметь canonical

## Правила мета-данных

```
title = "{Ключевая фраза} | {Название сайта}"
description = "{Уникальное описание с CTA и ключевым словом, 155-160 символов}"
```

Примеры:
```
title: "Кухни на заказ в Минске — изготовление от 14 дней | КухниПро"
description: "Кухни на заказ в Минске под размер вашего помещения. Бесплатный замер и 3D-проект. Гарантия 5 лет. Рассчитайте стоимость за 2 минуты."
```

## JSON-LD схемы

### Главная страница
- Organization
- LocalBusiness (NAP: Name, Address, Phone)
- WebSite с SearchAction

### Страница цен / главная / FAQ
- FAQPage

### Портфолио
- ItemList
- ImageObject

### Статьи блога
- Article
- BreadcrumbList

### Локальные страницы
- LocalBusiness с address города

## Правила перелинковки

- Главная → Каталог, Цены, Портфолио
- Каталог → Подкатегории, Цены, Портфолио
- Портфолио кейс → Схожие кейсы, Каталог, Контакты
- Блог статья → Каталог (если уместно), Цены, Портфолио
- Локальная страница → Каталог, Контакты, Портфолио с этим городом

## Локальное SEO

- Google Business Profile (отдельно настраивается)
- Яндекс Бизнес
- NAP-консистентность (имя, адрес, телефон — одинаковые везде)
- LocalBusiness JSON-LD на всех локальных страницах
- Отдельная страница для каждого обслуживаемого города

## Запреты

- Нельзя создавать страницы с одинаковым контентом (дорвеи)
- Нельзя дублировать городские страницы с заменой только названия города
- Нельзя использовать hidden text или keyword stuffing
- Нельзя делать страницы только для SEO без полезного контента
