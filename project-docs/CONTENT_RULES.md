# Правила контента

## Тональность (Tone of Voice)

- **Уверенная** — компания знает своё дело, не оправдывается
- **Практичная** — конкретные факты, цифры, сроки
- **Понятная** — без технических терминов для обычного читателя
- **Прозрачная** — реальные цены, реальные фото, реальные сроки
- **Локальная** — чувствуется привязка к Минску и региону

## Запрещено в текстах

- Вода и общие слова: "качественный", "индивидуальный подход", "широкий ассортимент"
- Ложные обещания без конкретики
- Цены "от X" без пояснения что входит
- "Мы рады приветствовать вас на нашем сайте"
- Обращение в третьем лице: "наша компания предлагает"

## Правила CTA

- CTA всегда конкретный: не "Узнать больше", а "Рассчитать стоимость кухни"
- Первичный CTA: "Рассчитать стоимость" / "Получить бесплатный проект"
- Вторичный CTA: "Смотреть портфолио" / "Узнать цены"
- CTA на мобильных: "Позвонить" / "Написать"
- После каждого смыслового блока — CTA

## Правила локальных страниц

- Каждая локальная страница уникальна — не копировать контент
- Упоминать конкретные районы и объекты города
- Локальный телефон / адрес (если есть)
- Кейсы из этого города
- Специфика доставки и монтажа в этом регионе
- Нельзя создавать страницы-дорвеи с одинаковым контентом

## Правила кейсов (портфолио)

Каждый кейс обязательно содержит:
- Реальное фото (не рендер)
- Площадь кухни (м²)
- Стиль
- Материал фасада
- Диапазон стоимости (или точная цена)
- Срок изготовления и монтажа
- Город / район
- Краткое описание задачи клиента
- Решение

## Правила статей блога

- Заголовок: H1 по коммерческому или информационному запросу
- Минимум 800 слов
- Подзаголовки H2/H3
- Конкретные советы с цифрами
- Внутренние ссылки на каталог, цены, портфолио
- CTA в середине и конце статьи
- Мета-описание 155-160 символов

## Правила отзывов

- Отзывы не публикуются автоматически — только через модерацию
- Статусы: new → pending → published / rejected / deleted
- Подтверждённые отзывы помечаются (верифицированный клиент)
- Поддельные или фейковые отзывы запрещены
- Отзыв должен содержать: имя, город, текст, опционально — фото
