# Обзор проекта

## Бизнес-цель

Создать коммерческий SEO-сайт по продаже кухонь на заказ, который генерирует заявки из органического поиска, карт и прямых заходов. Основной KPI — количество заявок в месяц.

## Целевая аудитория

### Первичные сегменты
- Владельцы квартир в Минске и области — нужна кухня под заказ
- Владельцы новостроек — первый ремонт
- Люди после ремонта или на стадии ремонта
- Семьи, заменяющие старую кухню
- Клиенты: дизайн + функциональность + цена

### Вторичные сегменты
- Владельцы частных домов
- Маленькие кухни и нестандартные помещения
- Клиенты по стилю: минимализм, классика
- Сегменты по бюджету: эконом, средний, премиум

## География

**Этап 1 (запуск):**
- Минск
- Минская область

**Этап 2 (масштабирование):**
- Москва
- Санкт-Петербург

## MVP-приоритеты

1. Главная страница с сильным конверсионным блоком
2. Каталог с фильтрацией
3. Портфолио с реальными кейсами
4. Калькулятор / квиз для сбора лидов
5. Локальные SEO-страницы под Минск и область
6. Мобильная версия с CTA-панелью

## Конкурентные преимущества сайта

- Прозрачный расчёт стоимости (не "цена по запросу")
- Реальные фото проектов с метражом и ценой
- Калькулятор с сегментацией по бюджету
- Локальная привязка к Минску с конкретными адресами
- Понятная система гарантий и этапов работы
- Быстрый отклик на заявку (обещание в форме)

## Позиционирование

Современный, надёжный сервис без излишней пафосности. Тональность: уверенная, практичная, прозрачная. Акцент на реальность: реальные фото, реальные цены, реальные сроки.
